# Каталог книг

Vue-приложение каталога книг с авторами, фильтрами, отчётом и подписками.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Вход для демонстрации: `admin` / `admin123`.

## Публикация

После отправки изменений в `main` проект автоматически публикуется на GitHub Pages:
https://peremitins.github.io/infotech-test-task/

## Структура проекта

- `src/views` — страницы приложения;
- `src/components` — переиспользуемые компоненты по сущностям;
- `src/api` — клиент REST API;
- `src/mocks` — локальная реализация демонстрационного API;
- `src/composables` — общая логика Composition API.

## Возможности

- каталог книг с поиском, фильтрами и пагинацией;
- страницы книг, авторов и отчёта;
- авторизация и CRUD для книг и авторов;
- создание книги с несколькими авторами и обложкой;
- подписка на новые книги автора.
